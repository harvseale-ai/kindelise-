# Archived Documentation

These files are retained for project history and assessment traceability. They
are not implementation authorities for the running Kindlelise MVP.

The active documentation is:

- [`README.md`](../../README.md) — setup, product, architecture, testing and
  assessment handoff;
- [`docs/VERTICAL_SLICE.md`](../../docs/VERTICAL_SLICE.md) — implemented MVP
  boundary; and
- [`docs/DECISIONS.md`](../../docs/DECISIONS.md) — accepted architecture
  decisions and their rationale.

This archive contains:

- completed build records: `IMPLEMENTATION_PLAN.md`,
  `IMPLEMENTATION_PROGRESS.md` and `MASTER_INSTRUCTION_PROMPT.md`;
- superseded student design references: `ARCHITECTURE.md`, `DATA_MODEL.md`,
  `PRIVACY_MODEL.md`, `PRODUCT_RULES.md`, `REQUIREMENTS.md`, `SAFETY_MODEL.md`
  and `WIREFRAMES.md`;
- earlier production-scale material: `PRODUCTION_ARCHITECTURE.md`,
  `ARCHITECTURAL_INVARIANTS.md`, `TRACEABILITY.md`, `DEPLOYMENT.md`,
  `MODERATION.md`, `PRODUCT.md`, `THREAT_MODEL.md` and `USER_FLOWS.md`; and
- two identical GovernedRecall README references retained under distinct names
  to preserve where the supplied template copies came from.

README files below `_achive/master_architecture/` remain beside that archived
scaffold because they describe its internal test directories.
